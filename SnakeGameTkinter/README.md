# Snake — Tkinter Edition

A polished Snake game made with Python's built-in Tkinter library. It has a dark arcade-style interface, score tracking, a best score counter, pause/resume, restart, and both arrow-key and WASD controls.

## Run it

Make sure Python 3 is installed, then run:

```bash
python main.py
```

No third-party packages are required.

## Controls

- Arrow keys or `WASD`: move
- `Space`: pause or resume
- `R`: restart

The game also starts automatically when you press a movement key.
